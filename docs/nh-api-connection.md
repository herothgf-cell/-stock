# 실제 NH PLUG API 연결

StockJournal v0.2.1의 Windows 화면과 2026-11-01에 확인한 NH 공식 안내를 기준으로 작성했습니다. 개인 계좌에 대한 실제 연결 성공 여부는 아래 조회 결과로 확인합니다. 개발용 합성 응답 테스트의 통과가 실제 사용자 인증 성공을 뜻하지는 않습니다.

## 1. NH에서 키 발급

1. [NH PLUG 홈페이지](https://www.nhplug.com/)에서 **API 사용신청**으로 들어갑니다.
2. NH 계좌로 로그인하고, 약관·유의사항을 확인하여 서비스 신청을 완료합니다. 본인인증은 NH 화면에서 직접 진행합니다.
3. **APPKEY**와 **APP Secret**을 발급받습니다.

NH는 고객번호당 하나의 APP KEY를 발급하며, 같은 고객번호에 연결된 여러 계좌에서 사용할 수 있다고 안내합니다. 실제 조회 가능한 계좌는 API가 반환하는 계좌 목록으로 확인합니다. 접근토큰은 프로그램이 발급·갱신하므로 별도로 복사할 필요가 없습니다. [공식 서비스 이용안내](https://www.nhplug.com/howto-use)

앱키와 앱시크릿만 아래 프로그램 설정에 직접 입력합니다. 접근토큰은 프로그램이 처리하며, 계좌 비밀번호를 이 앱에 입력할 필요는 없습니다. 키·시크릿·접근토큰·계좌 비밀번호는 채팅이나 GitHub에 올리지 않습니다. 연결 지원에 필요한 것은 발급 완료 여부와 조회 결과입니다.

## 2. 프로그램에 입력

`StockJournal.exe`를 실행하고 **설정 · 계좌 → NH 연결**에서 입력합니다.

| NH에서 발급받은 값 | 프로그램 항목 |
| --- | --- |
| APPKEY | NH 앱키 |
| APP Secret | NH 앱시크릿 |

**시세 갱신 간격(초)**은 처음에는 `60`으로 두고, 자동 갱신은 첫 수동 조회가 성공한 뒤 켜면 각 단계를 확인하기 쉽습니다. **설정 저장**을 누릅니다.

현재 앱은 나무 PLUG 운영 서버를 사용합니다. NH 모의투자 서버를 선택하는 설정은 없습니다. 자동 실행의 **DRY_RUN**은 앱 내부의 주문 없는 모의 실행이며 NH 모의투자 계좌 연결과 다릅니다. 첫 연결 확인은 자동 실행을 중지한 상태에서 아래 조회 버튼으로 진행합니다.

키와 연결 계좌번호는 Windows 사용자별 DPAPI로 암호화하여 로컬에 저장합니다. 매매일지 백업·기록 동기화에 포함하지 않습니다. 다른 PC에서는 키를 다시 입력하고 기존 계좌 별칭에 다시 연결합니다.

## 3. 계좌 목록으로 인증 확인

**설정 · 계좌 → 나무 계좌 가져오기**를 누릅니다. 별도 연결 테스트 버튼은 없습니다. 이 작업에서 토큰 발급과 계좌 목록 조회를 수행하며, 주문은 제출하지 않습니다.

계좌 목록이 나타나면 사용할 계좌를 고르고 **선택 계좌 연결**을 누릅니다.

- 초기 기록을 이미 가져왔다면 **연결할 기존 계좌**에서 해당 NH 별칭을 선택합니다. 같은 계좌를 새 별칭으로 중복 생성하지 않도록 실제 계좌를 대조하세요.
- 기록에 없는 계좌라면 새 별칭과 계좌 종류를 지정합니다.
- 목록의 `운영 · 일반`, `운영 · 주문대리인`, `모의투자`는 API 환경 구분입니다. ISA·연금저축·IRP 같은 상품 구분은 별도로 지정합니다.
- 모의투자 계좌는 현재 실제 매매일지 연결에서 제외합니다. API가 제공하지 않는 계좌는 수동 관리를 유지합니다.

계좌를 연결하면 하단에 잔고 대조 또는 체결 조회를 사용할 수 있다는 안내가 표시됩니다. 이 단계의 성공만으로 잔고·해외 시세·주문 권한까지 확인된 것은 아닙니다.

## 4. 조회 기능을 차례로 확인

| 순서 | 메뉴와 입력 | 확인할 결과 |
| --- | --- | --- |
| 잔고 | **설정 · 계좌 → 나무 잔고 대조**, 계좌 및 국내/미국 선택 | 나무 보유 수량과 기존 매매일지의 차이 |
| 체결 | **매매 기록 → NH 체결 조회**, 계좌·시장·시작일·종료일 | 실제 거래가 있었던 하루 또는 며칠의 체결 후보 |
| 시세 | 상단 **시세 갱신** | 원장에 보유 중인 국내·미국 종목의 가격·수신 시각 |

잔고 대조는 원장에 거래를 추가하지 않습니다. 기존 초기 자료가 있으면 먼저 수량만 비교하세요. **선택 종목 기초 보유 검토**는 과거 거래가 없는 종목에만 사용하는 별도 초기 입력 기능입니다.

체결 조회 기간은 `YYYY-MM-DD`로 입력합니다. 결과는 **일괄 가져오기** 검토 화면에 표시되며 즉시 저장되지 않습니다. 기존 엑셀·구글 시트에서 가져온 거래와 중복되는지 확인한 뒤 필요한 행만 저장하세요. 같은 거래를 서로 다른 자료에서 가져온 경우 자동으로 모두 중복 판별되는 것은 아닙니다.

현재가 조회 대상은 **매매일지에 양수 보유량이 있는 국내·미국 종목**입니다. 계좌 연결만 한 빈 원장에서는 조회 대상이 없다는 안내가 나올 수 있습니다. 이 안내만으로 인증 실패라고 판단하지 않습니다.

조회가 확인되면 **설정 · 계좌 → NH 연결 → 앱 실행 중 국내·미국 보유 종목 현재가 자동 갱신**을 선택하고 저장합니다. 30초 이상 간격의 주기 조회이며, PC와 앱이 실행 중일 때만 작동합니다.

## 5. 200티큐 연결과 실제 주문

200티큐에 사용할 계좌는 TQQQ·SPYM·SGOV의 조회·거래가 가능한 미국 주식 계좌로 지정합니다. 먼저 미국 잔고와 시세를 확인하고 [200티큐 설정](strategy-200tqqq.md)의 예산·보유량·일봉·수익률을 확인합니다.

**자동 실행 · 주문 상태**의 기본값은 DRY_RUN입니다. LIVE는 실제 주문을 제출하는 별도 기능이므로 API 연결 확인에 사용할 필요가 없습니다. 연결 확인 이후에는 [자동 실행 안내](automation.md)에 따라 해당 PC에서 계좌와 한도를 검토합니다. 개발 과정에서 실제 사용자 계좌 주문을 검증한 상태는 아닙니다.

## 연결 결과를 전달할 때

다음 정보면 연결 지원을 진행할 수 있습니다. 모든 항목을 미리 준비할 필요는 없고, 완료한 단계까지만 알려주세요.

```text
프로그램 실행 / 버전:
PLUG 서비스 신청 / 키 발급: 완료 또는 진행 중
초기 기록 가져오기: 완료 또는 아직
연결할 계좌: 별칭, 종류, 국내/미국 여부
200티큐용 미국 계좌: 있음 또는 없음
계좌 목록 조회: 성공 또는 실패
잔고 / 체결 / 시세 조회: 성공한 단계
실패한 메뉴, 발생 시각, 앱에 표시된 오류 문구:
```

전체 계좌번호는 필요하지 않습니다. 화면을 공유할 때는 키·시크릿·개인정보·잔액을 가리고 오류 안내만 남깁니다. 인증 요청 URL, 토큰, 비밀 저장 파일, 사용자 데이터 폴더 전체를 보내지 않습니다. 앱이 일부 오류를 일반화하여 표시하므로 실패 단계와 시각을 함께 확인해야 합니다.
