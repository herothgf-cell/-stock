# 연결 범위와 검증의 한계

## 금액과 거래

Decimal 정밀도 50으로 계산하며 이동평균 원가를 기본으로 합니다. 연결된 엑셀 물량은 해당 물량 원가를 적용합니다. 매수 비용은 원가에, 매도 비용은 실현손익에 반영합니다. 배당은 실제 수령액에서 세금을 차감합니다. 증권사별 세무 원가, 신고용 계산, 환율 환산, 예수금 원장, 분할·병합·합병·권리 변동, 공매도·파생상품은 구현 범위 밖입니다.

NH 주문별 누적체결에는 정확한 체결 시각이 없을 수 있습니다. 같은 날짜는 숫자 주문번호 순서로 제안하지만 실제 매수·매도 체결 순서와 다를 수 있으므로 사용자가 처리 순서를 확인해야 합니다. 총 체결금액을 수량으로 나누는 단가는 유한 Decimal 정밀도에서 아주 작은 반올림 잔여가 있을 수 있습니다.

통화별 합계를 분리하고 시세가 없는 보유분의 평가 합계를 미조회로 표시합니다. 가격 캐시에는 수신 시각이 있으며 앱이 꺼지면 갱신하지 않습니다.

## 외부 자료

NH 공식 문서에 맞춘 국내 종목·현재가·체결 어댑터입니다. 공개 종목 목록의 실제 파싱과 인증 API의 모의 응답 검증은 구분해야 합니다. **실제 사용자 NH 키로 로그인·현재가·체결 조회를 검증하지 않았습니다.** 계좌 권한과 실제 응답은 설정 후 확인해야 합니다. 해외 상장 자동 가격 공급자는 연결하지 않았으며 가격 직접 입력은 가능합니다.

이미지 OCR의 한국어 언어팩과 Windows 버전별 실행은 별도 환경 확인이 필요합니다. Windows 검사에는 영어 합성 이미지의 종목 코드·수량·가격을 실제 OCR 엔진으로 읽는 테스트와 배포 스크립트 포함 검사가 있습니다. 런타임·언어팩이 없는 환경에서는 통합 테스트의 제외 사유를 표시합니다. 모든 증권사 이미지의 표 구조를 자동으로 해석한다고 보장하지 않습니다. 추출 결과를 수정·검토한 뒤 저장합니다.

ETFcheck는 사이트 링크입니다. 자동 배당 스크래핑이나 증권사 실제 배당 입금의 자동 수집은 없습니다. 보유 종목과 입력된 참고 일정을 연결하고, 엑셀·CSV·수동으로 관리합니다. 기존 구글 시트 실시간 연동은 없으며 엑셀/CSV로 내보내 가져옵니다.

## 보관·동기화

공개 코드 저장소와 별도 비공개 원장 저장소를 사용합니다. 앱은 동기화 전과 업로드 전에 비공개 여부를 확인합니다. 저장소 소유자가 나중에 공개로 바꾸는 동작을 앱이 막을 수는 없습니다. 원장 JSON은 비공개 Git 이력에도 남으며 자체 암호화하지 않습니다.

인증값은 Windows DPAPI 사용자 범위로 암호화합니다. Windows 이외의 소스 실행에서는 메모리에서만 유지합니다. 각 PC에서 토큰·키를 다시 입력합니다. 파일이 동기화되기만 하면 앱이 항상 최신 상태라고 가정하지 마세요. PC 변경 전후 동기화를 확인합니다.

앱은 단일 사용자용입니다. 한 PC의 동일 데이터 폴더에는 한 프로세스만 접근합니다. Dropbox/OneDrive로 열린 SQLite 파일을 직접 동시에 공유하는 구조가 아닙니다.

동기화 원장의 크기 한도는 20,000,000바이트입니다. 1 MB가 넘는 종목 목록·원장은 GitHub의 동일 파일 버전(blob SHA)을 확인해 읽습니다. 한도를 넘으면 기존 기록을 유지하고 동기화를 중단합니다.

## 배포 검사

GitHub Actions는 합성 원장만 사용해 단위 테스트, 소스 GUI 여섯 화면 생성·캡처, PyInstaller EXE 생성, 실제 EXE 실행·종료를 검사합니다. 성공한 작업 링크와 smoke JSON으로 결과를 확인하세요. 실사용자의 개인 원본·인증키는 빌드에 포함하지 않습니다. 실행 파일에 상업용 코드 서명 인증서는 포함하지 않습니다.
