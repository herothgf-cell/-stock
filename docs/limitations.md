# 연결 범위와 검증의 한계

## 금액과 거래

Decimal 정밀도 50으로 계산하며 이동평균 원가를 기본으로 합니다. 연결된 엑셀 물량은 해당 물량 원가를 적용합니다. 매수 비용은 원가에, 매도 비용은 실현손익에 반영합니다. 배당은 실제 수령액에서 세금을 차감합니다. 증권사별 세무 원가, 신고용 계산, 환율 환산, 예수금 원장, 분할·병합·합병·권리 변동, 공매도·파생상품은 구현 범위 밖입니다.

NH 주문별 누적체결에는 정확한 체결 시각이 없을 수 있습니다. 같은 날짜는 숫자 주문번호 순서로 제안하지만 실제 매수·매도 체결 순서와 다를 수 있으므로 사용자가 처리 순서를 확인해야 합니다. 총 체결금액을 수량으로 나누는 단가는 유한 Decimal 정밀도에서 아주 작은 반올림 잔여가 있을 수 있습니다.

통화별 합계를 분리하고 시세가 없는 보유분의 평가 합계를 미조회로 표시합니다. 가격 캐시에는 수신 시각이 있으며 앱이 꺼지면 갱신하지 않습니다.

## 외부 자료

NH 공식 문서에 맞춘 계좌 목록·국내/미국 잔고·현재가·체결·미국 일봉 어댑터입니다. 공개 종목 목록의 실제 파싱과 인증 API의 모의 응답 검증은 구분해야 합니다. **실제 사용자 NH 키로 로그인·조회·주문을 검증하지 않았습니다.** 계좌 권한과 실제 응답은 설정 후 확인해야 합니다. 해외 자동 조회는 미국 현금 주식/ETF 범위이며 다른 시장은 수동 관리합니다.

NH 일봉 명세는 분할·배당 조정 여부를 보장하지 않습니다. 원문 전략은 TQQQ의 200일선을 사용하므로 자료를 확인하지 않으면 신호/자동 실행을 차단합니다. 자동 보정했다고 표시하지 않습니다. 현재 가격 확인은 해당 자료의 해시에 연결되며, 자료가 바뀌면 다시 확인해야 합니다. 이 단계는 완전히 무인으로 운영하는 데 남는 제약입니다.

실제 계좌의 환차손 포함 TQQQ 수익률은 사용자가 해당 종가일 기준으로 입력합니다. USD 참고 수익률을 원화 계좌 수익률로 대신하지 않습니다. 수익률 입력 없이도 하향 이탈·분할 진입 조건은 평가하지만 익절 자동 판단은 제한됩니다.

## 자동 주문과 복구

첨부 Toss 3.96의 실행 구조를 참고해 독립적으로 구현했으며 그 프로그램의 전략 기본값을 그대로 복사하지 않았습니다. 기본은 DRY_RUN이고 실제 체결을 원장에 만들지 않습니다. LIVE는 사용자가 로컬에서 명시적으로 켜야 합니다. 미국 정수주 현금 지정가 주문만 다룹니다. NH의 주문번호 반환은 접수 확인이며 체결 완료가 아닙니다.

NH 명세에 클라이언트 주문 멱등키가 없어 타임아웃 후 안전하게 같은 주문을 재전송할 수 없습니다. 전송 결과가 불명확하거나 부분 체결이면 후속 주문을 차단하고 실제 주문을 대조해야 합니다. 취소 접수도 취소 완료로 보지 않습니다. 여러 PC에서 같은 계좌의 자동 실행을 동시에 켜는 운영은 지원하지 않습니다. 실행 원장은 해당 PC 전용이며 다른 PC의 원장 동기화가 자동 주문을 인계하지 않습니다.

미국 예정 거래 달력은 2026~2028년 공식 휴장/조기 종료 일정입니다. 임시 휴장·개별 종목 정지·NH 시간외 거래 제공 여부까지 달력만으로 보장하지 않으므로 최신 NH 시장 상태와 함께 확인합니다. 앱/PC가 종료되면 예약 조회와 신규 실행은 멈추지만 접수된 주문은 증권사에 남을 수 있습니다.

이미지 OCR의 한국어 언어팩과 Windows 버전별 실행은 별도 환경 확인이 필요합니다. Windows 검사에는 영어 합성 이미지의 종목 코드·수량·가격을 실제 OCR 엔진으로 읽는 테스트와 배포 스크립트 포함 검사가 있습니다. 런타임·언어팩이 없는 환경에서는 통합 테스트의 제외 사유를 표시합니다. 모든 증권사 이미지의 표 구조를 자동으로 해석한다고 보장하지 않습니다. 추출 결과를 수정·검토한 뒤 저장합니다.

ETFcheck는 사이트 링크입니다. 자동 배당 스크래핑이나 증권사 실제 배당 입금의 자동 수집은 없습니다. 보유 종목과 입력된 참고 일정을 연결하고, 엑셀·CSV·수동으로 관리합니다. 기존 구글 시트 실시간 연동은 없으며 엑셀/CSV로 내보내 가져옵니다.

## 보관·동기화

공개 코드 저장소와 별도 비공개 원장 저장소를 사용합니다. 앱은 동기화 전과 업로드 전에 비공개 여부를 확인합니다. 저장소 소유자가 나중에 공개로 바꾸는 동작을 앱이 막을 수는 없습니다. 원장 JSON은 비공개 Git 이력에도 남으며 자체 암호화하지 않습니다.

인증값은 Windows DPAPI 사용자 범위로 암호화합니다. Windows 이외의 소스 실행에서는 메모리에서만 유지합니다. 각 PC에서 토큰·키를 다시 입력합니다. 파일이 동기화되기만 하면 앱이 항상 최신 상태라고 가정하지 마세요. PC 변경 전후 동기화를 확인합니다.

앱은 단일 사용자용입니다. 한 PC의 동일 데이터 폴더에는 한 프로세스만 접근합니다. Dropbox/OneDrive로 열린 SQLite 파일을 직접 동시에 공유하는 구조가 아닙니다.

동기화 원장의 크기 한도는 20,000,000바이트입니다. 1 MB가 넘는 종목 목록·원장은 GitHub의 동일 파일 버전(blob SHA)을 확인해 읽습니다. 한도를 넘으면 기존 기록을 유지하고 동기화를 중단합니다.

## 배포 검사

GitHub Actions는 합성 원장만 사용해 단위 테스트, 소스 GUI 일곱 화면 생성·캡처, PyInstaller EXE 생성, 실제 EXE 실행·종료를 검사합니다. 검증한 소스가 main의 최신 소스일 때만 EXE와 SHA-256 정보를 루트에 게시합니다. 성공한 작업 링크와 smoke JSON으로 결과를 확인하세요. 실사용자의 개인 원본·인증키는 빌드에 포함하지 않습니다. 실행 파일에 상업용 코드 서명 인증서는 포함하지 않습니다.
